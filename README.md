# Smart Parking System using 8051 Microcontroller

## Overview

This project implements a basic Smart Parking System using the 8051 microcontroller, IR sensors, and LED indicators. The system detects vehicle occupancy in parking slots and provides real-time visual indication of slot availability.

The project demonstrates the fundamentals of embedded systems, sensor interfacing, and real-time monitoring using Embedded C.

---

## Features

- Real-time parking slot detection
- IR sensor based vehicle sensing
- Red/Green LED slot indication
- Continuous monitoring using 8051
- Low-cost embedded system design

---

## Technologies Used

- Embedded C
- 8051 Microcontroller
- IR Sensor Interfacing
- Digital I/O Programming

---

## Hardware Components

- 8051 Microcontroller
- IR Sensors
- Red and Green LEDs
- Resistors
- +5V Power Supply

---

## Working Principle

- IR sensors detect the presence of vehicles in parking slots.
- Sensor outputs are read by the 8051 microcontroller.
- Green LED indicates an empty slot.
- Red LED indicates an occupied slot.
- The system continuously monitors slot status in real time.
